# TC · 고객센터 (SCR-CSC-001·002·003)

- 기준: 고객센터_기능명세서_v0.7_20261101, 백엔드 `docs/api/support.md`·`ErrorCode.java`, 프론트 `features/{notice,faq,inquiry}`와 `pages/{notice,faq,inquiry}`
- 준비: 백엔드를 :8080에 띄우고 프론트는 `yarn dev`(:5173). 일반 회원 A·B(둘 다 로그인 가능)와 관리자 계정, 공지 12건 이상(고정 1건 포함, 본문 이미지 1건), FAQ 12건 이상(분류별), A의 문의는 0건·미답변·답변 완료를 각각 만들 수 있게 준비. 테스트 이미지(jpg·png·webp 각 1장, 10MB 초과 1장, 확장자만 바꾼 텍스트 파일 1개)
- 표기: P = 정상, N = 오류·경계값. 기대 결과의 따옴표 문구는 코드에 있는 그대로. "확인 필요"는 코드·계약에서 확정되지 않은 것
- 공통: 세 화면은 `member` 라우트라 미로그인이면 로그인 화면으로 간다. 서버 오류 문구는 서버 `message`를 그대로 보여 주는 곳이 있다
- 상태: 세 화면 모두 실제 API 연결됨(가짜 응답 없음). 남은 연결: FN-CSC-003-10(캐릭터 이미지 전송), 003-14(알림 쪽), 003-09·11·15(업로드 한도 백엔드 확인)
