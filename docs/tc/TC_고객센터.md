## 명세·요구사항과 코드가 어긋난 곳

- [문서] FN-CSC-001-05 — 명세는 상세에 조회수를 보인다고 하나 화면에 없다(서버가 조회수를 쓰지 않기로 2026-10-30 결정). 명세를 고쳐야 한다 (`docs/api/support.md`, `NoticeDetail.jsx`)
- [코드] FN-CSC-002-01 — 명세는 질문 목록에 카테고리 배지를 함께 표시한다고 하나 화면에 없다 (`FaqList.jsx`)
- [코드] FN-CSC-001-01 / FN-CSC-002-01 / FN-CSC-003-01 — 명세의 "최대 10페이지"를 지키는 코드가 없다. 쪽 번호는 10개씩 묶어 보여 줄 뿐 서버 쪽 수 상한도 없다 (`BoardPagination.jsx`, `docs/api/support.md`)
- [문서] FN-CSC-003-06 — 명세는 "7종"이라 하면서 이름을 10개(건강기록 문의·픽셀 캐릭터·플레이스·커뮤니티·포인트·결제·가계부·계정·로그인·기타) 나열한다. 서버 공통코드는 7개(건강기록·픽셀 캐릭터·플레이스·커뮤니티·포인트·결제·가계부 묶음·계정·로그인 묶음·기타)이고 화면은 응답 이름 그대로 쓴다 (`InquiryType.java`, `InquiryForm.jsx`)
- [결정] FN-CSC-003-09 — 명세 총 110MB, 서버 `max-request-size` 100MB(`application.properties.example`)이고 프론트는 총합을 검사하지 않는다. 명세 문장도 "최대 10개이미지 첨부 가능며"로 깨져 있다 (`ImageAttach.jsx`)
- [코드] FN-CSC-003-10 — 명세는 오류 캐릭터 이미지가 첨부된 채로 작성 화면에 연결된다고 하나, 화면은 이미지를 보여 주지 않고 서버가 제출 때 첫 첨부로 붙인다. 캐릭터 생성 완료 모달의 [오류 문의]는 `pixelCharSn`을 안 보낸다 (`InquiryWritePage.jsx`, `CharacterCreateModal.jsx`)
- [결정] FN-CSC-003-18 — 기능 설명에 "관리자는 삭제됨 필터로 조회만 한다"가 있으나 이 기능은 서버 문서 표에 "명세 없음(프론트 요청)"으로 남아 있고, 캐릭터 오류 문의 삭제 제외 규칙은 명세에 없다 (`docs/api/support.md`)
