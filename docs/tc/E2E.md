# E2E 테스트 시나리오

- 목적: 화면·기능 단위 TC(`TC_*.md`)로는 잡히지 않는 **도메인 사이 연동**을 사용자 여정 단위로 확인한다
- 기준: 각 도메인 TC와 같음(코드 origin/develop 0e1e99a 2026-11-10, 요구사항정의서 v0.10.6). 단계의 세부 기대 결과는 적어 둔 FN의 TC를 따른다. 이 문서는 **단계 사이에 값이 넘어가는지**만 따로 적는다
- 표기: ⛓ = 도메인 경계(이 시나리오에서 꼭 확인할 연동 지점), ⚠ = 지금 코드·서버 때문에 막히거나 일부만 되는 단계
- 우선순위: 상 = 출시 전 반드시, 중 = 2차 교차 테스트 때, 하 = 시간 날 때

## 준비

- 서버: 백엔드 :8080, AI 서버 :8000, 프론트 `yarn dev`(:5173). 알림·메일 확인용 메일함
- 계정: **A**(일반 회원, 반려동물 2마리·캐릭터 있음), **B**(일반 회원, 반려동물 1마리), **N**(가입 전 이메일), **관리자 C**
- 브라우저: 팝업 허용(AI 대화창·채팅 새 창). 두 계정을 동시에 보는 시나리오는 일반 창 + 시크릿 창
- 배치 실행: 관리자 배치 현황(`/admin/batches`)에서 수동 실행
