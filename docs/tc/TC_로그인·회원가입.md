  - 약관 목록은 서버가 준다(시드: 서비스 이용약관 · 개인정보 수집·이용 동의 · 만 14세 이상입니다 · 마케팅 정보 수신 동의[선택])
  - 인증번호 유효시간·재전송 간격·횟수·틀린 횟수 제한은 서버 설정이라 이 문서에 숫자를 쓰지 않는다. 확인 필요: 운영 설정값

- 공통: 입력칸 오류는 입력칸 아래 빨간 문구와 AI 매니저 말풍선이 함께 보이고, 폼 위 공통 알림(AuthNotice)에는 AI 말풍선이 알림 옆에 보인다. 서버 오류 문구는 서버가 준 `message`를 그대로 쓴다. 서버 5xx는 "일시적인 오류가 발생했어요.", 서버가 꺼졌거나 네트워크가 끊기면 "네트워크 연결을 확인해 주세요."가 기본 문구다
- 공통: 빈 칸이면 [로그인]·[인증코드 발송]·[중복확인]·[닉네임 설정 완료] 같은 버튼이 비활성이라 "~를 입력해 주세요." 빈 칸 오류는 대부분 화면에 나오지 않는다(추가-1). 비어 있을 때 문구가 나오는 곳은 해당 TC에 따로 적었다
