# TC · 로그인·회원가입 (SCR-ACC-001 · 002 · 011 · 012 · 020)

- 기준: 로그인·회원가입_기능명세서_v0.8_20261101 (기능 목록 시트), 백엔드 `docs/api/member.md`·`ErrorCode.java`, 프론트 `src/features/member`·`src/pages/auth`·`src/routes/ProtectedRoute.jsx`·`src/api/axios.js`, 마일스톤 `milestones/YAY.md`
- 준비
  - 백엔드 develop을 :8080에 띄우고 프론트는 Node 24로 `yarn dev`(:5173). 로그인·비밀번호 찾기·복구는 실제 서버를 쓴다
  - 계정: 회원A(이메일 가입 일반), 회원B(SNS 전용), 회원C(탈퇴 30일 이내), 회원D(탈퇴 30일 경과), 회원E(정지), 회원F(닉네임 설정 미완료·최종로그인 NULL), 관리자, 로그인 실패 4회 쌓인 계정. 인증번호를 받을 수 있는 메일함
  - 회원가입(SCR-ACC-001 이메일 가입)과 비밀번호 재설정(SCR-ACC-012)은 가짜 응답이다. 가짜 규칙: 이메일 `duplicate@example.com`=가입됨, `restore@example.com`=복구 대상, `fail@example.com`=발송 실패, 인증번호 `123456`만 성공(유효 3분), 번호 `01012345678`=중복·`01000000000`=조회 실패, 비밀번호에 `fail`이 들어가면 저장 실패, 중복 닉네임 `초코맘2`·`관리자`, 기본 닉네임 `행복한집사4821`
  - SNS 로그인(카카오·네이버·구글)은 제공자 앱 키와 백엔드 OAuth가 있어야 하며 지금은 미구현이라 실행하지 않는다
- 표기: P = 정상, N = 오류·예외. "확인 필요: ..."는 코드나 계약에서 기대 결과를 확인하지 못한 항목. 상태 표기가 없는 기능은 실제 서버 연결 상태
- 공통: 필드 오류는 입력칸 아래 문구와 AI 말풍선(AiErrorGuide)이 함께 보이고, 폼 위 공통 알림(AuthNotice)에는 AI가 알림 옆에 보인다
