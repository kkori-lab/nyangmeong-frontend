# TC · 공통레이아웃(COM) 수동 테스트 케이스

- 기준: 공통레이아웃_기능명세서 v0.8(20261101) SCR-COM-002~009, 백엔드 `docs/api/notification.md`·`member.md`(`/auth/me`)·`community.md`(`/chat-rooms`), `ErrorCode.java`, 프론트 `src/layouts`·`src/routes`·`src/features/notification`·`src/features/chat`
- 준비: 백엔드 :8080, 프론트 `yarn dev`(:5173). 계정 3개: 일반 회원 A(알림·채팅 여러 건), 알림 0건 회원 B, 관리자 C. 브라우저 폭은 PC 1280, 태블릿 900, 모바일 390으로 나눠 본다
- 표기: P = 정상, N = 오류·예외. 폭 경계(1100·760)는 정확히 그 폭과 한 칸 위·아래를 본다. "확인 필요: ..."는 코드·계약에서 기대 결과를 확정하지 못한 것
- 구현 상태: 알림·설정·인증 이동은 실제 API. 채팅 목록·대화·읽음·안 읽은 수(`features/chat/api.js`)는 가짜 응답. 가짜 응답 개발 확인용 쿼리 `?fakeChatRooms=0`(방 0건), `?fakeChatForbidden=1`(참여자 아님)
- 제외: SCR-COM-001은 명세에 없음(결번)

## 다른 도메인 화면에 걸친 기능

- 기능 ID 행 중 다른 도메인 화면 ID를 가진 행은 없다. 요구사항 ID 칸에만 다른 도메인(MAN·CMU·MYP·ACC·AIM)이 걸린다. 이동 대상 화면(SCR-MYP-005 5-3·SCR-MYP-002·SCR-MYP-011·SCR-MYP-030·SCR-CSC-003·SCR-CMU-005·SCR-AIM-011)은 각 도메인 케이스에서 확인한다
