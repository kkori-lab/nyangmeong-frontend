  - 영수증 TC는 jpg·png·webp 실제 영수증 사진, 약봉투 사진, 글씨 없는 사진, 11MB 파일, PDF, 확장자만 바꾼 파일을 준비한다
  - 사전 알림(SCR-AIM-006) TC는 관리자 계정으로 `POST /api/admin/batches/SYSC0007/run`을 부르고, 메일은 메일 sandbox로 확인한다. DB `NOTI_SNDNG_LOG`를 볼 수 있어야 한다
