# TC · 플레이스 (SCR-HOS-001, SCR-PLC-001~004)

- 기준: 플레이스_기능명세서_v0.5_20260930, 백엔드 `docs/api/place.md`(초안)·`ErrorCode.java`, 프론트 `features/place`·`pages/place/PlacePage.jsx`(`/places`), `milestones/YAY.md`
- 준비
  - 백엔드를 :8080에 띄우고 프론트는 Node 24로 `yarn dev`(:5173). 회원 계정으로 로그인한다
  - 지도는 `VITE_KAKAO_MAP_KEY`가 있어야 보인다(키 값은 적지 않는다). 백엔드 `app.kakao-local.*` 키가 없으면 업체가 가짜로 나온다
  - 즐겨찾기가 있는 계정과 없는 계정을 하나씩 준비한다. 주소는 `/places?category=hospital|beauty|goods|pet-friendly|hotel`
  - 이 화면에는 위치 권한 요청이 없다(코드에 `geolocation` 없음). 위치 허용/거부 TC는 없고, TC-HOS-001-05-03에서 이를 확인한다
- 표기: P = 정상, N = 오류·경계. 화면 문구는 코드 그대로 쓴다. "확인 필요"는 명세·코드·계약에서 기대 결과를 정할 수 없는 것
- 상태: 검색·즐겨찾기 API 연결 완료(2026-11-03 사람 확인). 가짜 응답 없음. 연결 남음은 FN-HOS-001-33(라우트가 아직 `auth: 'public'`)
- 제외: FN-HOS-001-02·12·13·14는 명세에 번호가 없다(결번). 관리자 장소 메뉴 SCR-ADM-060은 2026-11-04 화면을 없앴으므로 다루지 않는다. 「전체」 탭은 명세에서 미정이라 화면에 없다
