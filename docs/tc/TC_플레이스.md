- 준비
  - 백엔드를 :8080에 띄우고 프론트는 `yarn dev`(:5173). 회원(일반 회원) 계정으로 로그인한다. 관리자 계정도 하나 준비한다

- 표기: P = 정상, N = 오류·예외. 화면 문구는 코드 그대로 쓴다. "확인 필요"는 명세·코드·계약으로 기대 결과를 정할 수 없는 것
- 제외: FN-HOS-001-02·12·13·14는 명세에 행이 없다(번호 비어 있음). 「전체」 탭은 명세에서 미정이고 REQ-HOS-001이 두지 않기로 했으며 화면에도 없다. 관리자 장소 메뉴는 이 TC 범위가 아니다
- 상태 요약: 검색·즐겨찾기 API와 로그인 필수 접근 모두 연결됨(가짜 응답 없음). 명세와 어긋나는 곳은 맨 아래 절에 있다
