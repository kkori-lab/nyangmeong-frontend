# TC · 커뮤니티 (SCR-CMU-001~005)

- 기준: 커뮤니티_기능명세서_v0.8_20261101, 백엔드 `docs/api/community.md`·`ErrorCode.java`, 프론트 `src/features/community`·`news`·`chat`
- 준비: 백엔드 develop을 :8080에 띄우고 프론트는 Node 24로 `yarn dev`(:5173). 회원 계정 3개(작성자 A, 다른 회원 B·C)와 관리자 계정 1개. 커뮤니티 전 화면이 로그인 필요(`member`)라 모든 TC는 로그인 상태가 기본이다
- 표기: P = 정상, N = 오류·예외·경계. "확인 필요: ..." = 코드·계약에서 기대 결과를 확인하지 못한 항목
- ID: `TC-CMU-<화면번호>-<기능번호>-<순번>`. 따옴표 안 문구는 코드 그대로다. 서버 오류 문구(`ErrorCode.java`)는 화면에 그대로 나오는 경우만 적었다
- 제외: FN-CMU-004-03 결번, FN-CMU-003-06 뉴스 수집(서버 RSS 배치, 프론트 화면 없음)
