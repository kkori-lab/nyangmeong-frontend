# TC · 메인페이지 (SCR-MAN-001)

- 기준: 메인페이지_기능명세서_v0.10_20261103, 프론트 `pages/main/MainPage.jsx`와 `features/dashboard`
- 준비: 프론트 `yarn dev`(:5173), 로그인 가능한 회원 4명: 반려동물 0마리, 1마리, 2마리 이상, 공동양육 반려동물이 있는 회원. 팝업 차단을 끈 브라우저와 켠 브라우저 각각
- 표기: P = 정상, N = 오류·경계값. 따옴표 문구는 코드 그대로. "확인 필요"는 코드·계약에서 확정되지 않은 것
- 상태: 반려동물 목록(`usePets`, `GET /pets`)만 실제 서버 값. 건강 지표·검진·처방·AI 리포트·케어미션은 `dashboardSample.js`의 고정 샘플이다. 서버 연결 전이라 아래 TC의 "기대 결과"는 현재 화면 기준이고, 명세 기준 결과가 다른 곳은 "확인 필요"로 적었다
- 화면 URL `/main`은 `member` 라우트. 미로그인이면 로그인 화면으로 이동한다
