- 상태: 5개 화면 모두 실제 API 연결 완료(가짜 응답·미구현 없음, `milestones/JAJ.md`). 검사결과지 PDF 분석(FN-HLT-005-04, 007-04·06)은 AI 서버 `POST /ai/checkups/lab-results`, 영수증 인식 결과 확인 모달(FN-HLT-002-34~46)은 AI 서버 `POST /ai/receipts`로 만든 영수증이 있어야 확인할 수 있다
- 준비
  - 백엔드 :8080, `yarn dev` :5173(Node 24), AI 서버(PDF·영수증 TC용, `LLM_API_KEY` 필요)
  - 계정 A: 주양육자, 반려동물 2마리 이상(예: 초코·뭉치). 계정 B: 반려동물 1마리. 계정 C: 공동양육자로 연동된 계정. 계정 D: 반려동물 0마리. 남의 반려동물 `petSn` 하나 메모
  - 계정 A 데이터: 검진기록 6건 이상(예방접종·정기검진 포함), 혈액검사 3회 이상(같은 항목 2회 이상), 처방약(복용중·종료), 반복 예방, 첨부(PDF·이미지), 관찰 항목(관찰중·종료), 일상 기록 15건 이상, 일정 여러 건, 영수증 사진(구역 1개·2개·없음)
  - 백엔드를 끄는 TC는 끄고 확인한 뒤 다시 켠다
- 표기: P = 정상, N = 오류·예외·경계값. "토스트"는 화면 하단 알림이며 서버가 준 `message`를 그대로 보인다(서버 꺼짐 "네트워크 연결을 확인해 주세요.", 5xx "일시적인 오류가 발생했어요."). 저장 성공은 별도 성공 토스트 없이 모달이 닫히고 목록이 갱신된다
- 화면 경로: 종합 건강기록 `/health`, 건강 일지 `/health/diary`(#hlt002-graph·#hlt002-obs·#hlt002-exam), 케어 캘린더 `/health/calendar`(#hlt003-calendar·#hlt003-care), 검진상세 `/health/pets/{petSn}/checkups/{ckupRcdSn}`, 검사 수치 입력 `/health/pets/{petSn}/checkups/{ckupRcdSn}/inspections`
